deckox-server

公開Web API

Endpoint状態レスポンス
GET/healthz実装済み{"status":"ok"}
POST/api/v1/auth/login実装済み単一管理者のログインとセッションCookie発行
GET/api/v1/auth/session実装済み現在の認証状態
POST/api/v1/auth/logout実装済みセッションを無効化
GET/api/v1/status実装済みServerの名前・バージョン・状態とAgent状態。Agent障害時はdegraded
GET/api/v1/system実装済みAgentのシステム情報APIを中継
GET/api/v1/system/capabilities実装済みホスト再起動がAgent設定で許可されているか取得
POST/api/v1/system/reboot実装済み管理者パスワードを再確認し、許可済みのホスト再起動をAgentへ要求
GET/api/v1/system/metrics実装済みAgentのリソースメトリクスAPIを中継
SSE/api/v1/events/metrics?interval=1|2|5実装済みCPU・メモリ・負荷平均を認証済みブラウザへ配信。購読者0件では採取を休止
GET/api/v1/terminal/status実装済み有効状態、同時接続数、無操作終了時間を取得
WS/api/v1/terminal/ws実装済み非root PTYの入出力と端末サイズ変更。同一Origin、2接続、15分無操作終了
GET/api/v1/storage実装済みAgentのストレージAPIを中継
GET/api/v1/services実装済みsystemdサービス一覧を中継
GET/api/v1/services/{id}実装済みsystemdサービス詳細を中継
POST/api/v1/services/{id}/{action}実装済み起動・停止・再起動。Agentの許可・エラー状態を維持して返却
POST/api/v1/settings/password実装済み現在のパスワードを確認し、Argon2idハッシュを更新して全セッションを失効。5分間に5回の確認失敗で制限
GET/api/v1/settings/ssh/keys実装済み管理対象ユーザーとDeckox管理下のSSH公開鍵を取得
POST/api/v1/settings/ssh/keys実装済みOpenSSH形式のSSH公開鍵を追加
DELETE/api/v1/settings/ssh/keys/{id}実装済みID指定でSSH公開鍵を削除
GET/*実装済みVue静的ファイル。未知のパスはindex.htmlへSPAフォールバック

deckox-agent

内部Agent API

Endpoint状態取得内容
GET/v1/health実装済みAgentプロセスのヘルス状態
GET/v1/status実装済みホスト名、OS、CPUアーキテクチャ、/proc/uptimeの秒数
GET/v1/system実装済みOS、バージョン、カーネル、ホスト名、稼働時間、boot ID、タイムゾーン
GET/v1/system/capabilities実装済み設定に基づくホスト再起動の許可状態
POST/v1/system/reboot実装済み許可時のみsystemctl --no-block rebootを実行
GET/v1/system/metrics実装済みCPU使用率・コア数、メモリ・Swap、ロードアベレージ
GET/v1/storage実装済みファイルシステム、形式、マウントポイント、容量・使用量
GET/v1/services実装済みロード済みsystemdサービス一覧と有効化状態
GET/v1/services/{id}実装済みサービス詳細、Main PID、操作許可状態
POST/v1/services/{id}/start実装済み許可リスト内のサービスを起動
POST/v1/services/{id}/stop実装済み許可リスト内のサービスを停止
POST/v1/services/{id}/restart実装済み許可リスト内のサービスを再起動
GET / POST/v1/ssh/keys実装済み設定済みユーザーのDeckox管理公開鍵を取得・追加
DELETE/v1/ssh/keys/{id}実装済み公開鍵を削除。最後のSSH接続鍵は拒否
Agent APIはTCPではなく、/run/deckox/agent.sock上で提供されます。

deckox-protocol

共有Protocol型

ServerとAgentが共有するSerialize/Deserialize可能なRust型です。

型状態内容
HealthResponse使用中Server・Agentのヘルス応答
AgentStatus使用中AgentからServerへ返すホスト状態
SystemInfoほか使用中システム、メトリクス、ストレージ、サービスの応答型
SystemCapabilities使用中Agent設定に基づくホスト再起動の許可状態
RealtimeMetricsEvent使用中SSEの連番、取得時刻、Agent接続状態、メトリクス、エラーコード
ServiceAction使用中systemdサービスの起動、停止、再起動
CommandResult使用中操作完了時のコマンドID、実行状態、メッセージ
SshKeyListほか使用中SSH公開鍵の一覧・追加要求・鍵種別・SHA-256指紋
AgentCommand型のみ定義済み汎用コマンド型。現在のHTTPハンドラーでは未使用
サービス制御: 専用HTTPエンドポイントとServiceActionで実装されています。汎用AgentCommandは現在使っていません。
