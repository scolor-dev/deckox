Deckox documentation

Linux管理基盤の、現在地を読む。

DeckoxはVue管理画面、Axum Server、Linux Agentを1つのモノレポで管理するWeb管理基盤です。このサイトは現在の実装に対応する設計・機能・導入手順をまとめています。

Implementation status

現在の実装範囲

状態はリポジトリのコードを基準にしています。「定義済み」は型が存在していても、実行するAPIがまだ存在しないことを示します。

領域状態現在提供している内容
Web Server実装済みVue配信、単一管理者認証、パスワード変更、Agent APIの保護されたプロキシ、SSEメトリクス配信
System Agent実装済みシステム情報、CPU・メモリ、ストレージ、systemdサービス制御、SSH公開鍵管理
Vue UI実装済みリアルタイムグラフ、概要・サービス・ストレージ・設定の固有URL、日本語・英語、ブラウザ別表示設定、共通通知
Service command実装済み許可リストに登録したsystemdサービスの起動・停止・再起動
認証実装済みArgon2idパスワード、変更時の全セッション失効、12時間セッション、ログイン・パスワード再確認の試行制限、同一Origin確認
公開環境について: 管理者認証は実装済みですが、TLS終端は未実装です。インターネットへ直接公開できる段階ではありません。
